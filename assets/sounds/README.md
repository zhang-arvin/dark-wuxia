# 音效资源目录

本目录存放游戏所有音效文件。文件尚未就位，播放器会在文件缺失时静默跳过。

## 文件命名规范

### BGM（背景音乐，循环播放）

| 文件名 | 用途 |
|--------|------|
| `bgm_town.mp3` | 城镇背景音乐 |
| `bgm_battle.mp3` | 战斗背景音乐 |
| `bgm_boss.mp3` | Boss 战背景音乐 |

### SFX（音效，一次性播放）

| 文件名 | 用途 |
|--------|------|
| `sfx_attack.mp3` | 攻击 |
| `sfx_hit.mp3` | 受击 |
| `sfx_crit.mp3` | 暴击 |
| `sfx_drop.mp3` | 掉落 |
| `sfx_equip.mp3` | 装备 |
| `sfx_upgrade.mp3` | 升级 |
| `sfx_click.mp3` | 点击 |
| `sfx_page.mp3` | 翻页 |
| `sfx_retreat.mp3` | 撤退 |

## 格式要求

- **格式**: MP3（兼容性最佳）
- **采样率**: 44100 Hz
- **BGM 时长**: 1–3 分钟（循环播放）
- **SFX 时长**: 0.2–1.0 秒（短促明快）
